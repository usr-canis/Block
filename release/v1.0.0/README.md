# Roadscope 1.0.0

Signed Android APK, built from commit `22286d7` with version code 1 and version name 1.0.0. Minimum Android version: 8.0 (API 26).

Verify the APK before installing:

```sh
sha256sum --check SHA256SUMS.txt
```

The APK has no network permission. It collects on-device phone sensors and optional phone location; it does not read Google's Android Auto session or send telemetry anywhere. Read [`../../docs/FEASIBILITY.md`](../../docs/FEASIBILITY.md) before expecting vehicle-side fields.
